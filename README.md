## Overview

This repository provides optimized Java solutions for the 50 most frequently encountered LeetCode interview questions. These problems represent the essential foundations required for technical assessments at leading technology firms, covering core data structures and algorithmic patterns.

---

## Content Organization

Each source file within this repository corresponds to a specific LeetCode problem. The solutions are organized by their official LeetCode identification number to facilitate quick reference and lookup.

## Installation and Execution

To utilize these solutions locally, ensure you have the **Java Development Kit (JDK)** installed on your system.

### 1. Clone the Repository

```bash
git clone [https://github.com/your-username/LeetCode-Top-50.git](https://github.com/your-username/LeetCode-Top-50.git)
cd LeetCode-Top-50/src
```

### 2. Compile and Run

To verify a specific solution, use the standard Java compiler and runner. For example, to execute the solution for Question 1:

```bash
javac Question1.java
java Question1
```
